About Me

I'm a software engineer based in Chicago with over nine years of experience building backend systems in Java and Spring Boot. I spent more than seven years at APIsec, an API security testing company, where I grew from software engineer to senior engineer and ended up leading architecture decisions, code reviews, and mentoring newer developers.

Most of my work has been microservices, event-driven systems, and AWS-based deployments. These days I also build with NestJS, and I use AI tools like Claude Code and MCP-based agent workflows in my own projects.

I'm now working on my M.S. in Artificial Intelligence at Indiana Wesleyan University. My goal is to take what I know about shipping reliable software and use it to build AI systems that real people can depend on.

Personal Value Proposition

I help software teams, especially in healthcare, add AI to their products without putting users at risk. I bring nine years of production engineering to AI, so I pick the right approach for the problem, test the risky cases, and ship features that are reliable, secure, and ready for real users.
